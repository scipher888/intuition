The lighter-rigor opinion sibling to [Signal & Noise](https://www.signalandnoise.email). Hunches and arguments still in motion — the version of an idea I want to be true, set down while it is still forming. Not audited claims.

A static GitHub Pages site. AI tools draft and lightly pressure-test; the final wording, the opinions, and the errors are the author's.
